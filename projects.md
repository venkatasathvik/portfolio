# Projects Portfolio

Welcome to my projects directory. My work bridges the gap between digital logic design and real-world embedded applications. 
I focus on architecting synchronous RTL systems—such as high-throughput finite state machines in Verilog—alongside developing sensor-driven IoT nodes
and hazard-sensing hardware using microcontrollers and C/C++.

### Directory Overview

Below is a breakdown of the specific project folders included in this directory:

*   **esp32-accident-alert-iot:** A real-time tracking and accident detection embedded unit using an ESP32, ADXL345 3-axis accelerometer, and a NEO-6M GPS module. 
                                  Features custom I2C and UART driver logic in C/C++ and automated webhooks for low-latency telemetry.

*   **conveyor-belt-fsm-verilog:** A digital sorting controller designed in Verilog HDL. Implements a multi-state Mealy/Moore FSM synthesized 
                                   and simulated in Vivado to maintain high-throughput synchronous operation.

*   **vending-machine-rtl:** An automated coin-dispensing and inventory transaction controller utilizing synchronous sequential logic. 
                            Features a modular RTL architecture separating the datapath and control unit for optimized resource consumption.
